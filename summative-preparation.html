Git Commands You Need to Remember

git init

What does this do?

Creates a new Git repository in your project folder so Git can start tracking files.

Possible prompt(s) you may see on the test:

  • Initialize git in your summative folder
  • Ensure that Git has been initialized in your folder
git remote add origin #your-repository-url

What does this do?

Connects your local repository to a remote GitHub repository so you can push your work online.

Possible prompt(s) you may see on the test:

  • Set up your remote origin with your repository url
  • Add a remote repository url as your origin
Click here to see how to find your git repository url 
git pull

What does this do?

Downloads the latest changes from GitHub and updates your local files to match. However, since you will be creating a new site for the summative, you probably will not need to use this command 
git add .

What does this do?

Stages all changed files so they are ready to be included in the next commit. You can replace "." with actual file names to stage them respectively

Possible prompt(s) you may see on the test:

  • Stage all your changes to be ready for commit
  • Stage all the changes you've made to your site
git commit -m "you can type anything in here"

What does this do?

Saves a snapshot of your staged changes with a short description of what you changed.

Possible prompt(s) you may see on the test:

  • Commit your staged changes with a custom message
git push -u origin main

What does this do?

Uploads your committed work to GitHub and sets main as the default branch for future pushes.

Possible prompt(s) you may see on the test:

  • Push your committed changes while setting up an upstream to your origin's main branch
  • Push your changes now; Remember to set up the upstream if this is the first time

Other Useful Git Command

git remote -v

What does this do?

Shows the remote repository URLs linked to your project (used to check if origin is set correctly). You should see: 
origin  #your-repository-url (fetch)
origin  #your-repository-url (push)

git branch -M main

What does this do?

Renames the current branch to main, which is the standard default branch name.

Basic HTML Structure & What Tags to Use

The basic code layout should (always) be:

<html>
    <head>
        [Page Information]
    </head>
    <body>
        [Page Content]
    </body>
</html>

Click here to see a picture example of what <head> & <body> control respectively.

What goes inside <head>?

At this stage, you will only need to include two things in this section

<title>#your-site-title</title>

What does it do?

This change the tab text in the browser. Remember, this is NOT the actual title for your content 
<link href="css/global.css" rel="stylesheet" />

What does it do?

This grabs external stylesheet file from a given file path. Remember, rel="stylesheet" is essential for this to work

What goes inside <body>?

Basically the whole page content is held in this section. You need to learn how to sectionalize the page in order to achieve the layout you want.

1. To create different parts

<div>content</div> - Create a division
<section>content</section> - Create a section
<header>content</header> - Create a section that is usually used for logo & menu
<footer>content</footer> - Create a section that is usually used for contact information, map directions, and secondary links
<main>content</main> - Create a section that usually holds the main content of the page

Possible prompts you may see on the test

  • Create a __________ section
  • Separate into different parts

Example:

Please create a header and separate into three parts: logo, slogan, and menu 
<header>
    <div id="logo">[logo content]</div>
    <div id="slogan">[slogan content]</div>
    <div id="menu">[menu content]</div>
</header>

2. To create a clickable element that take you to another page

<a href="[link]">[element]</a>
  • [link] can be another page in your folder, so make sure you under file structure; it can also be an actual link (url)
  • [element] can be any element; such as pure text, or <img>

3. To display an image

<img src="[image file path]" />
  • [image file path] can be an image file in your folder, so make sure you under file structure; it can also be an actual link to an image (url)
  • Remember, <img> is a self-closing tag, meaning that it doesn't have a closing tag

4. To create a horizontal line

<hr />
  • Remember, <hr> is a self-closing tag, meaning that it doesn't have a closing tag

5. To add a paragraph

<p>[body of text]</p>

6. To create different headings

<h1>[text]</h1>
<h2>[text]</h2>
<h3>[text]</h3>
<h4>[text]</h4>
<h5>[text]</h5>
<h6>[text]</h6>
  • Remember, each page should only have one <h1> as the page heading
  • Heading tags stop at 6, so <h7> is NOT a thing; These are treated as sub-headings

First thing first

Before you start, it's important to understand how to write CSS.

[target element] { [rule 1 name]: [rule 1 value]; [rule 2 name]: [rule 2 value];}

[target element]

You can target one of the following three elements:

  1. An actual HTML element: <div>
  2. An element with specific ID given by you: #[id]
  3. An element with specific class name given by you: .[class]

[rule name] & [rule value]

This is the part where you actually have to memorize; however, Visual Studio Code has a build-in function that helps you auto-complete rules, it's essential for you to utilize it for efficiency

Common CSS rules you will need to use during the summative

margin-top | margin-right | margin-bottom | margin-left

Possible prompts

  • Create some space between these elements
  • Short-handed version: margin: top right bottom left
padding-top | padding-right | padding-bottom | padding-left

Possible prompts

  • Ensure the content doesn't start right away
  • Create enough space between the content and its container
  • Short-handed version: padding: top right bottom left
text-align

Possible prompts

  • Align the content in this container to the left|center|right
font-size

Possible prompts

  • Adjust the size of the text
color

Possible prompts

  • Change the text color
background-color

Possible prompts

  • Set the background color of this section to six-seven black;
border-width | border-style | border-color

Possible prompts

  • Wrap this element with a 4-pixel orange border
  • Short-handed version: border: width style color
